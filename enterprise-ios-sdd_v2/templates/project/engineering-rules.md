# Engineering Rules

## General

- No speculative product behavior.
- Keep changes scoped.
- Prefer existing project patterns before introducing new ones.

## Swift

- Follow the approved Swift/Xcode version.
- Prefer structured concurrency for new asynchronous code when approved by the stack.

## Testing

- New business logic requires automated tests.
- Changed behavior requires regression coverage.

## Dependencies

- New dependencies require justification and approval.
