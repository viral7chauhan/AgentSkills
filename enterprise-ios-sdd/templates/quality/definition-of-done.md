# Definition of Done

A feature is DONE only when all applicable requirements have evidence.

- [ ] All in-scope requirements implemented
- [ ] All acceptance criteria satisfied
- [ ] All plan items verified
- [ ] All required tasks verified
- [ ] Automated tests added/updated
- [ ] Automated tests pass
- [ ] Build passes
- [ ] Lint/format checks pass
- [ ] Architecture checks pass
- [ ] Security checks pass where applicable
- [ ] Accessibility checks pass where applicable
- [ ] Performance checks pass where applicable
- [ ] Traceability is complete
- [ ] Execution evidence is complete
- [ ] Convergence report has no blockers
- [ ] Documentation updated where required
- [ ] Human approval obtained for required approval gates

IMPLEMENTED != VERIFIED.
A checkbox alone is not evidence of completion.
